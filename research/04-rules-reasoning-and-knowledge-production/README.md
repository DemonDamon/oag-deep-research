# 04 · 规则推理与知识生产



本方向研究如何从文本、表格、图像、数据和标准中生产 **无歧义、可治理、可执行的规则知识库**。重点包括规则表示、抽取、冲突与依赖、版本、适用范围、执行引擎和可解释审计；规则作为领域知识资产，不等同于 Agent 的工具权限或工作流。



| 问题 | 预期交付 |

|---|---|

| 规则可用哪些形式表示，分别适合哪些约束、推理和审计任务？ | 规则表示谱系与选型矩阵 |

| 如何从法规、文档、表格、图像或数据源抽取候选规则并保留来源？ | 抽取流水线与溯源契约 |

| 如何治理冲突、引用依赖、执行顺序、版本和失效条件？ | 规则知识库治理模型 |

| 不同执行引擎与推理范式如何取舍？ | 引擎对比与基准计划 |

| 如何让 Agent 安全消费规则而不把候选规则自动变成行动？ | Rule Context Pack 与审批边界 |
